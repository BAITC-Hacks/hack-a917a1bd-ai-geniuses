# Синтетический комплект OrgLens

Все шесть документов содержат пометку «Синтетические демонстрационные данные». Компания и её документы вымышлены. Это небольшой пример для проверки приложения, а не реальные организационные документы.

Комплект **ДО** включает положение о Центре информационных технологий (DOCX), положения о закупках и бухгалтерии (текстовый PDF) и организационную структуру (XLSX).

Комплект **ПОСЛЕ** включает приказ о реорганизации (DOCX), положения о технических отделах (текстовый PDF) и матрицу ответственности (XLSX). В приказе прямо указаны разделение Центра, создание отдела информационной безопасности и сохранение закупок и бухгалтерии. Старое положение о Центре утрачивает силу; старые положения о закупках и бухгалтерии сохраняют действие.

Номера пунктов записаны непосредственно в документах. У DOCX страницам не присваиваются вымышленные номера: приложение использует абзацы и ячейки таблиц. У PDF доступна реальная страница, у XLSX — лист и адрес ячейки.

`expected_findings.json` — отдельный эталон для тестов и live-evaluation. Backend никогда не загружает его для анализа. Кнопка демо передаёт исходные документы в обычный процесс анализа. Без настроенного ключа OpenAI доступны документы и их фрагменты, но AI-результат не подставляется.

Пересоздание: `python scripts/generate_demo.py` из корня проекта. Нужны зависимости backend и `reportlab`; для PDF необходим шрифт Arial или DejaVu Sans. При необходимости укажите путь к TTF в `ORGLENS_DEMO_FONT`.
